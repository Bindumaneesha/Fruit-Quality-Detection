# Fruit-Quality-Detection

An end-to-end Deep Learning project that automatically classifies fruit quality using transfer learning with MobileNetV2. The application predicts whether a fruit is Fresh or Rotten (or the corresponding class labels in the dataset) from an uploaded image.

📌 Project Overview

Fruit quality inspection is an important task in supermarkets, warehouses, and food processing industries. Manual inspection is time-consuming and subjective.

This project uses Computer Vision and Deep Learning to automate fruit quality inspection by classifying fruit images.
